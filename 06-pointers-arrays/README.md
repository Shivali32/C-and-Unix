# Assignment 6: Pointers and Array Operations

Use pointers to modify arrays and return or inspect computed results.

## How It Works

The exercises ask for in-place duplicate handling, integer reversal, selected operations, minimum and maximum values, and array copying. Pointer arguments expose how functions access existing memory.

## Main Tasks

- Traverse arrays through pointer arguments.
- Modify data according to the question constraints.
- Test boundary cases with the sample arrays and values.
