# Assignment 1: Input Output and Arithmetic

Practice formatted output, user input, numeric variables, and arithmetic expressions in C.

## How It Works

The questions ask for a greeting, a sentence assembled from user input, arithmetic calculations, circle measurements, and arithmetic-progression terms.

## Main Tasks

- Read values with the required C input functions.
- Compute arithmetic and geometric results.
- Format each result according to the supplied examples.
