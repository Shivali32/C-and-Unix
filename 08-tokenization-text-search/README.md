# Assignment 8: Tokenization and Text Search

Design string-processing functions for tokenization, searching, replacement, XML parsing, and document search.

## How It Works

The specification describes the required interfaces, including a custom tokenizer that avoids strtok. Input text and delimiters are processed into tokens or matches, with several questions building on these text operations.

## Main Tasks

- Split text using the specified delimiter rules.
- Find or replace substrings and inspect XML content.
- Apply token-based processing to the search exercise.
