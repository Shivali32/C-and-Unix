# Assignment 10: Files and Record Updates

Work with persistent student records, file transformations, bitwise pairs, and debugging exercises.

## How It Works

A command file directs insertion, search, display, deletion, and course updates in a student-record file. Separate questions cover file manipulation, AND/OR/XOR operations, and diagnosing faulty C code.

## Main Tasks

- Parse record commands and their associated input values.
- Read and update the records file.
- Implement the remaining file, bitwise, and debugging exercises.
