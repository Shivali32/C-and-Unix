# Assignment 4: Functions and Simulation

Define C functions for probability, factorials, perfect numbers, simulation, and numeric series.

## How It Works

Each question specifies a computation and its arguments. The caller collects inputs, invokes the function, and displays the result; the dice exercise also introduces repeated random trials.

## Main Tasks

- Separate calculations into functions with explicit arguments.
- Use loops for factorials, divisors, and series.
- Follow the supplied rules for the craps simulation.
