# Assignment 9: Structures and Records

Represent invoices, vending-machine data, and record arrays with C structures.

## How It Works

The exercises define related records such as addresses, products, invoice line items, and machine inventory. Functions create or process those records and print the requested results; additional questions examine duplicate detection.

## Main Tasks

- Define structures that reflect the provided record layouts.
- Pass records to creation and output functions.
- Process arrays of records using the question examples.
