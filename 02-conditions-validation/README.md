# Assignment 2: Conditions and Validation

Use conditional statements to classify numbers and validate structured input.

## How It Works

The exercises ask for even-or-odd classification, triangle validation and classification, a basic calculator, and calendar-date validation.

## Main Tasks

- Check numeric conditions before selecting an output.
- Validate triangle angles and calendar components.
- Choose calculator operations from user input.
