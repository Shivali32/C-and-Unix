# Assignment 3: Loops and Number Processing

Use loops to generate strings, inspect integer values, and print repeated patterns.

## How It Works

The problems ask for two-letter domain names, prime factorization, reverse Fizz-Buzz, reversed binary output, and a diamond made from star characters.

## Main Tasks

- Generate combinations with nested loops.
- Apply integer division and remainder to number problems.
- Control spacing and repetition for printed patterns.
