# Assignment 5: Arrays Strings and Similarity

Manipulate character and integer arrays and compare sets of terms.

## How It Works

The questions cover k-gram generation, a student directory, duplicate removal, Jaccard similarity, and merging sorted arrays. They connect array indexing with reusable functions and text comparison.

## Main Tasks

- Generate fixed-length substrings from a character array.
- Manage and compare directory or token entries.
- Remove repeated values and merge ordered data.
