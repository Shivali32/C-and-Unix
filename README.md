# C and Unix Programming

This repository collects the C291 assignment specifications for introductory systems programming with C and Unix. The exercises progress from compiling a small program and handling input to conditions, loops, functions, arrays, pointers, text comparison, structures, and file-backed records. The assignment PDFs define the problems, required function interfaces, example inputs, and expected outputs. The text-processing assignments connect tokenization and similarity measures to grading and search tasks, while the later record exercises use structures and file operations to maintain application data. The collection is organized around the supplied specifications; the small compiler examples accompany Assignment 0.

## Assignments and Labs

- **[Assignment 0: Compiler and Git Setup](00-compiler-and-git-setup/)**  
  Compile a C program with GCC, run the executable, and submit the source through Git.

- **[Assignment 1: Input Output and Arithmetic](01-input-output-arithmetic/)**  
  Practice formatted output, user input, numeric variables, and arithmetic expressions in C.

- **[Assignment 2: Conditions and Validation](02-conditions-validation/)**  
  Use conditional statements to classify numbers and validate structured input.

- **[Assignment 3: Loops and Number Processing](03-loops-number-processing/)**  
  Use loops to generate strings, inspect integer values, and print repeated patterns.

- **[Assignment 4: Functions and Simulation](04-functions-simulation/)**  
  Define C functions for probability, factorials, perfect numbers, simulation, and numeric series.

- **[Assignment 5: Arrays Strings and Similarity](05-arrays-strings-similarity/)**  
  Manipulate character and integer arrays and compare sets of terms.

- **[Assignment 6: Pointers and Array Operations](06-pointers-arrays/)**  
  Use pointers to modify arrays and return or inspect computed results.

- **[Assignment 7: Text Answer Grading](07-text-answer-grading/)**  
  Design an answer-grading exercise based on cosine similarity between student and reference text.

- **[Assignment 8: Tokenization and Text Search](08-tokenization-text-search/)**  
  Design string-processing functions for tokenization, searching, replacement, XML parsing, and document search.

- **[Assignment 9: Structures and Records](09-structures-records/)**  
  Represent invoices, vending-machine data, and record arrays with C structures.

- **[Assignment 10: Files and Record Updates](10-files-record-updates/)**  
  Work with persistent student records, file transformations, bitwise pairs, and debugging exercises.
