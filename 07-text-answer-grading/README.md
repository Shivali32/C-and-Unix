# Assignment 7: Text Answer Grading

Design an answer-grading exercise based on cosine similarity between student and reference text.

## How It Works

The assignment asks for tokenization, term-frequency vectors, dot products, vector magnitudes, and conversion of similarity into marks. The reference questions and answers supply the comparison text.

## Main Tasks

- Read a student answer for each reference question.
- Build term counts and calculate cosine similarity.
- Convert similarities into per-question and total marks.
